# Helm

Helm is a lightweight infrastructure control plane for personal homelabs.

It provides a unified API for monitoring devices, executing actions, and orchestrating services from dedicated hardware remotes, web dashboards, and custom clients.

## Goals

- Lightweight
- Extensible
- API-first
- Device agnostic
- Self-hostable

## Planned Features

- Dashboard
- Device Management
- Actions
- Metrics
- Notifications
- Plugin System
- WebSocket Events
- ESP32 Remote Support

## Stack

- Go
- Chi
- SQLite
- WebSockets
